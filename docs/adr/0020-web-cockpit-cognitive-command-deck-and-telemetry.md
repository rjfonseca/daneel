# ADR 0020: Web Cockpit Cognitive Command Deck, Quick-Action Presets, and Introspective Telemetry

* Status: accepted
* Date: 2026-09-18

## Context and Problem Statement

Following the introduction of the Web Cockpit streaming architecture (ADR 0013), Agent Evaluations (ADR 0018), and the Metacognitive Dream Engine (ADR 0019), Daneel gained deep introspective profiling and continuous agent calibration. However, the Web Cockpit interface had three major gaps:

1. **Invisibility of Cognitive & Metacognitive Telemetry**: The rich introspective data generated by ADR 0019 (stage timings, latency bottlenecks, cross-domain syntheses) and ADR 0018 (agent evaluation items, missed opportunities, and knowledge gaps) was only accessible via CLI flags (`--stats`) or raw JSON inspection in `.daneel/cache/`. The web visualizer lacked a dedicated cockpit view for monitoring agent learning and engine performance.
2. **Operational Dispatch Friction**: Standard routine maintenance (e.g., executing a dream cycle with profiling, auditing agent transcripts for missed opportunities, running vault doctor checks, tidying links, or scanning workspace repositories) required manually searching through a growing catalog of routines and entering parameters.
3. **Terminal Observability & Trace Export**: Engineers diagnosing complex skill outputs or multi-step routine logs in `CyberTerminal` lacked search filtering across verbose outputs and had no native export mechanism to download terminal traces for offline debugging or agent transcript analysis.

## Decision Drivers

* **Cognitive Telemetry Parity**: Provide full visual parity for ADR 0018 (agent evals) and ADR 0019 (engine phase profiling) within the web interface without polling or heavy overhead.
* **1-Click Operational Ergonomics**: Provide instant quick-action preset buttons for high-frequency operations (`dream`, `audit_agents`, `doctor`, `tidy`, `workspace`).
* **Terminal Search & Log Export**: Add real-time log search filtering with match counters and a one-click timestamped `.txt` download for diagnostic output.
* **Keyboard & Telemetry Ergonomics**: Implement `Ctrl+Enter` dispatch, `Esc` dismissal, and a global refresh button (`RefreshCw`) for immediate telemetry updates.
* **Strict Invariants**: Comply fully with the English UI Invariant, CGO-free Go backend, and zero-drift WebFS synchronization (`task web-verify-sync`).

## Considered Options

* **Option 1: CLI-Only Inspection**: Retain cognitive metrics and transcript evaluations strictly as CLI reports (`daneel dream --stats` and `daneel audit agents`).
  * *Disadvantages*: Silos cognitive telemetry away from the interactive galaxy visualizer; poor developer ergonomics during interactive pairing sessions.
* **Option 2: Standalone Dashboard Page**: Build a separate web page or route outside `CockpitModal`.
  * *Disadvantages*: Fragmented user experience; separates routine execution from telemetry monitoring; requires additional routing and layout state.
* **Option 3: Integrated Cognitive Command Deck in CockpitModal with ConnectRPC Streaming**:
  * Expand ConnectRPC service with `GetCognitiveTelemetry` endpoint.
  * Introduce a third tab (`Agent & Metacognition`) in `CockpitModal`.
  * Add a 1-Click Quick-Action Presets bar to the Actions Deck.
  * Add search filtering and log download to `CyberTerminal`.

## Decision Outcome

Chosen option: **Option 3: Integrated Cognitive Command Deck in CockpitModal with ConnectRPC Streaming**.

### Architecture & Data Flow

```
                      Browser Cockpit Modal
                                │
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
     Actions Deck         Staff Telemetry     Agent & Metacognition
  (Quick Presets Bar)    (7-Day Allocation)    (ADR 0018 & 0019)
          │                                           │
          │ ConnectRPC Stream                         │ ConnectRPC Unary
          ▼                                           ▼
   ExecuteRoutine()                         GetCognitiveTelemetry()
          │                                           │
          ▼                                           ▼
   daneel serve                                GraphServer
  (CLI Subprocess /                          ┌────────────────────────┐
   Headless Routine)                         │ .daneel/cache/         │
          │                                  │  dream_handoff.json    │
          ▼                                  │  agent_learnings.json  │
   CyberTerminal                             └────────────────────────┘
  (Search & Export)
```

### Key Capabilities

1. **ConnectRPC Cognitive Telemetry Protocol (`api/v1/graph.proto`)**:
   - `GetCognitiveTelemetry`: Returns `last_cycle_duration_ms`, `stage_timings`, `bottlenecks`, `induced_syntheses`, `evolution_log_path`, `scanned_turns`, `missed_opportunities_count`, `knowledge_gaps_count`, `recent_evals`, `total_files_scanned`, and `broken_links_count`.
   - Populated from `.daneel/cache/dream_handoff.json` (introspective dream report) and `.daneel/cache/agent_learnings.json` (agent feedback history).

2. **Cockpit Metacognition Dashboard (`CockpitModal.tsx`)**:
   - **Summary Big Numbers**: Dream Duration, Latency Bottlenecks, Missed Opportunities, Knowledge Gaps, and Scanned Turns.
   - **Dream Engine Profiling**: Visual phase timing bars (duration in milliseconds and percentage of total cycle duration) with descriptions.
   - **Bottleneck Alerts**: Highlight phases exceeding 35% latency thresholds, or render optimal throughput status.
   - **Cross-Domain Syntheses**: List induced conceptual bridge notes scaffolded during the dream cycle.
   - **Agent Calibration Ledger**: Interactive feed of recent evaluations classified as `MISSED OPPORTUNITY`, `KNOWLEDGE GAP`, or `USER CORRECTION` with suggested remediation actions.
   - **Audit Action Button**: 1-click trigger to execute `audit_agents` routine directly from the metacognition tab.

3. **Quick-Action Presets Row**:
   - Prominently situated at the top of the Actions Deck.
   - 1-click dispatch for `dream` (with `--stats`), `audit_agents`, `doctor`, `tidy`, and `workspace`.

4. **CyberTerminal Search & Download (`CyberTerminal.tsx`)**:
   - Dynamic search filter toggle with case-insensitive filtering.
   - Active match counter (`X / Y matched`) and quick query clear button.
   - Timestamped file export (`daneel-terminal-YYYY-MM-DDTHH-mm-ss.txt`).

5. **Keyboard Shortcuts & Refresh**:
   - `Ctrl+Enter` dispatches the currently selected routine from anywhere within the modal.
   - Global `RefreshCw` button re-aggregates routines, staff telemetry, and cognitive telemetry simultaneously.

## Consequences

### Positive
* Complete visibility into agent learning loops, engine bottlenecks, and knowledge synthesis within the web visualizer.
* Drastically reduced operational friction for common vault maintenance routines.
* Enhanced debugging and audit capabilities via searchable, downloadable terminal output.
* 100% CGO-free Go backend and zero external dependencies.

### Negative / Trade-Offs
* Additional ConnectRPC method and proto structures to maintain.
* Slightly increased bundle size (~3 kB) for client-side search and export logic.
